# 📖 FOOTBALL API BACK-END <a name="about-project"></a>

> Football API is a RESTful API that provides real-time and historical football data, including fixtures, player statistics, team details, and league standings.

## 💻 Getting Started <a name="getting-started"></a>

> To get a local copy up and running, follow these steps.

### Prerequisites


### Setup

Clone this repository to your desired folder:

```sh
  cd projects
  git clone git@github.com:Felix45/foota-api.git
```

In order to run this project you need to run the following command:

```sh
  npm install
```

### Usage

To run the project, execute the following command:

```sh
  node index.js
```

### Run tests

To run tests, run the following command:


```sh
  npm test
```

### Deployment

You can deploy this project using:
 - Heroku
 - Digital Ocean
 - Amazon web services
